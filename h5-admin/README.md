# 统一运营后台（H5 desktop）

盛杰运营平台的统一后台原型，对应三应用拆分（小程序 A + 小程序 B + 统一后台）中
后台的部分。桌面端浏览，与 [`../h5-expo`](../h5-expo)、[`../h5-liren`](../h5-liren)
同一品牌族：暖纸底、锈红主色、金色表示钱、紫色表示 AI；标题衬线、数值等宽。

**签名交互**：工作台的「到账流水」每 5 秒实时进一笔增值订单，金色闪光滑入，
今日到账的英雄数字同步跳动——把会议纪要里「叮叮叮到账」做成看得见的东西。

---

## 本地跑起来

```bash
python3 -m http.server 8766 --directory /Users/donis/dev/ai-business
```

浏览器开 `http://localhost:8766/h5-admin/`，桌面窗口即可（≥960px 是设计尺寸，
窄屏会自动折叠侧栏，仅作兜底）。

**演示话术模式**：URL 加 `?script=1`，顶栏右侧出现「话」按钮，内容为当前视图的
讲法与会议纪要原话。

## 7 个视图

| 路由 | 视图 | 讲什么 |
| --- | --- | --- |
| `#/overview` | 工作台 | 今日到账英雄数字 + 实时到账流水 + 渠道排行 + 分账提现 + 增值进度 + 运营任务 |
| `#/events` | 活动 | 活动即模板：美博会 / 减肥产业大会 / 闭门会 / 线上社群一张表；已结束活动可出复盘报告 |
| `#/ops` | 运营计划 | T-60→T+14 五阶段传播节奏 + 今日素材下发状态 + 一键生成明日全员素材包 |
| `#/channels` | 渠道 | 全渠道漏斗（触达→打开→登记→到场）+ 一人一码归因表 + 防刷说明 |
| `#/exhibitors` | 参展商 | 签约 / 审核 / 增值统计 + 每家的邀客三数、增值包、到场提醒状态 |
| `#/finance` | 订单与分账 | 订单表（已支付/已分账/退款中）+ 70/20/10 分账规则 + 结算与可提现 |
| `#/ai` | 社群与 AI | 请求 vs 实际推理双柱图（缓存差值 = 毛利）+ 群同步与社群广场分层 |

## 能点的地方

- **一键生成明日全员素材包**（运营计划页）：逐条打点 5 个步骤——读取 126 家品牌与展位、
  按冲刺期口径生成差异化文案、套三种展会规格、敏感词校验标记 2 条待复核、
  打包下发——最后给出「已生成 168 套素材」。这一条是「每家品牌发的不是同一张图」的证明。
- **会后复盘报告**（活动页，已结束的「老会员激活」那行点「复盘报告」）：
  转化漏斗 + 四个关键指标 + 三条结论（好 / 待改 / 风险）+ 下一轮建议，可导出 PDF。
- 到账流水自动进账（离开工作台自动停止；`prefers-reduced-motion` 下不做动画）。
- 图表与进度条悬停有 tooltip（渠道条、双柱图、增值进度）。
- 「申请提现」「组织切换」为 toast 演示；「重置演示」刷新页面。
- 左侧导航六个视图秒切，`Esc` 关闭弹层。

## 数据与设计约定

- 纯静态，无后端、无网络请求、无依赖；所有数字为演示排布，
  且与 h5-expo 移动端主办方看板完全一致（¥12,460 / 126 家 / 70/20/10 / ¥96,480），
  演示时手机和电脑两块屏幕对得上。
- 图表用色 `#933428`（请求/主系列）、`#5E4793`（AI/推理）、`#BD7221`（金额），
  已通过色板校验（CVD ΔE 17.4，对比度 ≥3:1）；文字一律用墨色，不用系列色。
- 单轴、细柱、末端 4px 圆角、双系列图带图例 + 末日直接标数。
- AI 算力账口径：1,284 次请求 · 87% 缓存命中 · 实际推理 167 次 ·
  成本 ¥70.1 vs 收入 ¥2,180 → 毛利率 96.8%，即「一万人请求只算一次」。

## 部署

线上地址：**https://www.aibuzz.cn/admin-demo/**（带话术：`?script=1`）。

`bash scripts/deploy-h5.sh` 会把本目录同步到测试机 `/opt/h5demo/admin-demo`，
nginx（aibuzz-ssl.conf）中对应 `/admin-demo/` 的 location。
注意：`/admin/` 路径已被 admin.aibuzz.cn 的生产 Next.js 反代占用，不要使用。
