图标来源 / Icon attribution
===========================================================================

本项目 miniprogram/styles/icons.wxss 中内联的全部图标来自 Remix Icon。

  Remix Icon 4.x
  https://github.com/Remix-Design/RemixIcon
  Licensed under the Apache License, Version 2.0

图标以 base64 data-URI 的形式内联在 icons.wxss 里（每个图标已按设计稿配色
预先着色），通过 Iconify 的公开 API 取得原始 SVG：
  https://api.iconify.design/ri/<name>.svg?color=<hex>

重新生成：
  python3 scripts/build_icons.py

不要手改 icons.wxss —— 它是生成文件。要增删图标请改 scripts/build_icons.py
里的 ICONS 表后重新生成。
