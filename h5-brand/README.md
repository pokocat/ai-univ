# 品牌 H5 · 贴牌演示套件

会员社群产品的**白标 H5 演示**：同一套页面与交互，按品牌换身份、配色、字体、材质与内容，构建期出静态包。
第一个品牌是「丽人公社（暂定）· 第 34 期 美博会特刊」，面向美业门店老板与店长。

> 这是给客户与销售讲解用的**演示**：数据是样例（页面上逐项盖「样 / 样张 / 拟定」），
> 不登录、不收款、不收集任何信息；登录与开通一律「下转小程序」。
> 两张照片（开窗静物、展馆通道）是**生成的示意图**，正式使用前须换成授权实拍或正版图库；
> 铝箔、压纹封口与镭射膜三张材质图由 `scripts/gen-textures.py` 程序生成。

设计体系、品牌层与「加第二个品牌」的步骤见 [DESIGN.md](DESIGN.md)。

## 屏幕

| 路由 | 页面 | 要点 |
| --- | --- | --- |
| `#/` | 本期 | 黛蓝盒面首屏（刀版开窗、超细字标、插舌标签）→ 本期所含（成分表）→ 使用方法 → 附赠小样 → 展会信息 |
| `#/plans` | 会员方案 | 体验装 / 正装 / 尊享礼盒三种规格，选规格时盒子比例随之变化；开通走「下转小程序」 |
| `#/course/:id` | 课程详情 | 折叠说明书样式 |
| `#/benefits` | 权益 | 按会员档位分级的成分表 |
| `#/join` | 入群说明 | 开通后怎么进班级群，每步附小程序里会看到的样张状态 |
| `#/card` | 会员证样张 | 镭射防伪条，白底二维码，明确标注非有效会员码 |
| `#/me` | 我的 | 游客态；关于本演示、重置演示 |

签名交互：**附赠小样**——按住易撕口沿虚线拖开（有等效按钮，减少动效时直接完成），露出展期日程并生成手机日历文件（`.ics`，写明「拟定」）。

## 本地运行

需要 Node.js ≥ 22.18（测试直接加载 TypeScript 源文件）。

```bash
cd h5-brand
npm install
npm run dev          # 本地开发，BRAND 默认 liren
npm run typecheck
npm run build        # 产物在 dist/<品牌>/，相对路径，可放在任意子路径下
npm test             # 守卫：零第三方网络、禁用词、每页「样张」、字体预算、展示字体覆盖、内容契约
```

预览构建产物：

```bash
python3 -m http.server 8766 --directory dist/liren
```

浏览器打开 `http://localhost:8766/`，建议用约 390×844 的手机视口。

## 品牌层

一个品牌 = `brands/<id>/` 下的三样东西：

- `brand.json`：品牌名、暂定标注、期号、底栏标签等身份信息；
- `h5.json`：颜色角色、字阶、间距、材质、动效、展会信息（每条带 confirmed / 拟定）与模块顺序；
- `content/`：`preview.json`（与会员端游客预览接口逐字段同形的演示数据）和 `extras.json`（没有接口来源的演示材料，逐项标注）。

改了页面标题或课程标题后，若 `npm test` 提示展示字体缺字，运行 `node scripts/subset-display.mjs` 重新生成字体子集
（首次在新环境运行加 `--fetch`，会下载 Noto Sans SC 源字体并校验哈希）。

## 字体与许可证

- 西文与数字：Archivo（OFL），自托管子集；
- 中文展示字：Noto Sans SC（OFL）子集，只含实际用到的展示文字，更名为 `Brand Display SC`；
- 正文中文走系统字体；全程零第三方字体请求。许可证随字体一起发布（`src/fonts/OFL*.txt`）。
