# 小程序 B · 丽人公社 · AI 学习社群（H5 mobile）

社群 + AI 军师 + 会员 + 门店经营台。设计稿来源：Claude Design 项目
`美博会AI社群Demo.dc.html`（丽人公社双小程序方案）中 **小程序 B** 的 6 屏。

> 产品判断：社群做成**消息列表**，不做成一个新 App。四个超级智能体（军师 / 教官 /
> 店长 / 财务官）和群聊、通知并排出现在同一个列表里，像同事一样，零学习成本。
> 展会侧的预登记小程序在 [`../h5-expo`](../h5-expo)。

## 一、社群广场融进了消息页

会议纪要里客户的原话是「社群跟消息其实是同一个」。所以广场不做成独立板块，
而是把三个高价值群作为**「你没进的群」直接混在会话列表里**，和自己的会话同列：

```
[军] AI 军师                      刚刚 ❶
[社] AI 学习社群·32人             10:24 ❻
[教] 超级教官 / [店] 超级店长 / [财] 超级财务官
[会] 美博会组委会
────────────────────────────────────
 广场 · 你没进的群，内容同步过来        全部 ›
 ① 第 8–12 天服务断点 · 3 群 41 条讨论
────────────────────────────────────
[闭]🔒 品牌老板闭门群       今日 +5 精华
      ▒▒模糊的第一条预览▒▒        [¥9.9]
[IP]🔒 主理人 IP 操盘群     今日 +8 精华
[高]🔒 盛杰·高端合作群      今日 +2 条  [仅主理人]
```

**付费墙长在会话行上**：锁徽章 + 高斯模糊预览 + 金色 ¥9.9 价签，三件套同时在场，
落在首屏内不用滑。点一行弹半屏预览（第一条清晰、其余模糊），底下就是价格。

**解锁后同一行就地变态**——锁变绿开锁、模糊消失、价签变「已解锁」、时间从
「今日 +5 精华」变成真实时间戳，四处一起变。演示时「花 9.9 之前 / 之后」的对比
发生在同一个位置，这是这一版说服力最强的一下。

分层规则不变：免费每群只看第 1 条 · ¥9.9 单群 30 天 · 学习会员全场 · 高端群限品牌主理人。
搜索框过滤自动覆盖广场行（同为 `.thread`），全被滤掉时分区带跟着收起。

## 二、运营 tab：照搬温泉酒店的经营主线逻辑

参见 [`../README.md`](../README.md)（温泉酒店 demo 的业务说明）。同一套骨架换行业：

**`#/ops` 开屏只有两样**——AI 军师算出的「今天该做的一件事」，和五步主线卡在第几步。
刻意不放功能宫格。第 3 步「拉新」是琥珀空心圈（比其他点大），那就是卡住的地方：
上月 1,268 个新客只有 291 个档案在门店手上，其余散在 6 个店长的个人微信里。

**`#/studio` 模板按经营问题分类**：第二周留人 / 新客到店 / 老客回头 / 同城券——
不会出现「换脸」「数字人」这类技术词。统一脚本《陪跑教练手记》全国 1,270 家门店共用，
各家只换教练和门店，对应温泉的《汤泉客栈》。

**`#/produce` 最关键的是那个开关**：客户做完在镜前扫码出自己的打卡片，9.9 一条，
上月 1,340 条挣了 1.3 万。**现场把它关掉**再说一句「关掉它，拉新只是纯成本，
客资照样留在店长手上」——这是全场最能打动老板的一下，和温泉版一样。

**`#/assets` 数字资产库**：形象带时间轴（2019 一店 / 2023 六店 / 2026 在用，
三期分别活体核验分别授权）、场景带空间参数（机位角度、距离、色温、logo 墙留白）、
资产可外借按次分成。合规是硬约束并写进了文案：体测区禁瘦身滤镜、客户影像走单独授权柜、
三期形象不得并列出现（避免被读成体型前后对比）。

**积分体系**贯穿三处：出片扣分（15 分/条）、带客赠分、商城抵扣。点右上角积分胶囊查看。

## 今日群报

群聊页顶部「生成今日群报」出一张深紫分享卡：日期、群名、今日条数、三条要点、
一句金句、底部二维码。可转发拉新——同一群同一天只生成一次，全员复用（缓存复用的产品化表达）。

在 `#/plans` 切换等级，全站跟着变（存 `localStorage`，刷新保留）：

## 能点的地方（都是真的）

- **AI 军师对话**（核心动线）：点「上传腾讯会议记录」→ 出现会议纪要附件卡 → 军师
  打字动画 → 追问；共 3 轮问答，答完按钮变「查看报告」，报告有 1.3 秒生成过程。
  也可以自己在输入框打字回答，会用你打的内容当气泡。进度存本地，刷新继续。
- **群聊**：输入框发言后超级店长会脚本化回一句（演示用，不是真模型）。
- **诊断报告**：「导出 PDF」调系统打印（已写打印样式，顶栏/tab/按钮不进纸）；
  「预约 1 对 1 复盘」弹出排期选择。
- **门店经营台**：「查看名单」弹出 30 天未到店客户（号码已脱敏）；「确认发送」
  把 18 条回访排进发送队列并回到群里。
- **美博会组委会**那条会话跳回 `../h5-expo/`，两边同源共用 `localStorage`，
  预登记填的姓名 / 企业会显示在会员页和报告抬头上。

## 数据与合规

- 纯静态：**没有后端、没有一个网络请求**，状态写在本机 `localStorage`
  （键前缀 `lrgs:`，与小程序 A 共用）。现场断网也能演。
- 军师不是真模型，是脚本化对话；这样做是刻意的——演示时节奏可控，做出人工顾问
  的质感。真接模型时把 `js/data.js` 里的 `JUNSHI` 换成接口返回即可。
- 门店数据、复购率、席位、会员价格全部为模拟数据，不构成任何承诺。
- 涉及体重管理的表述**限于经营与服务流程**，不构成疾病诊断、治疗建议或疗效承诺；
  报告第 05 板块和经营台底部都写明了这一条，演示时不要跳过。
- 回访名单手机号已脱敏；真实客户健康数据的采集与使用需单独取得授权。

## 为什么这个 app 里没有摄影图

这是一个「消息 / 聊天」形态的产品，靠对话密度和结构化卡片说话，塞大图反而像营销页。
所以视觉资产只有两类：底部 tab 的内联 SVG 图标（`js/app.js` 的 `ICONS`，跟随
`currentColor` 变色、选中态加粗），以及用系统宋体脚本化渲染的「丽」字应用图标。
展会侧的主图和论坛缩略图在 [`../h5-expo`](../h5-expo)。

## 演示话术（对应设计稿右栏）

**`#/messages` 把社群做成消息，不做成 App**
- 首页就是消息列表，所有人都会用，零学习成本。
- 超级教官、超级店长、超级财务官这些智能体，和群聊、通知并排出现在同一个列表里，像同事一样。
- 企业微信群的内容同步进来，用户在这里看到的还是他熟悉的对话。
- 纪要：「你的理想性，是把微信产品改成了社群逻辑，这是最好用的，因为我们所有的人都是很习惯使用微信了。」

**`#/square` AI 机器人在群里干活**
- 群里有人提问，智能体直接接话，不需要跳出去打开另一个工具。
- 军师在群里给的是结构化卡片——数据、结论、下一步，不是一段闲聊。
- 群消息量本身就是运营指标，哪个群活、哪个群死，后台一目了然。
- 纪要：「包括社群，AI 机器人，怎么在社群中工作？」

**`#/junshi` 把腾讯会议记录喂给军师**
- 一对一沟通完，会议记录丢进来，军师开始追问——节奏由我们控制，做出人工顾问的质感。
- 追问 2 到 3 轮才出报告，客户会觉得这是有人在认真研究他，而不是一个按钮。
- 这条动线就是筛客户的动线：聊完我基本能判断这个客户值不值得深度跟进。
- 纪要：「腾讯会议记录聊完以后，我们其实就丢给军师，军师按照我们的方式出报告。」

**`#/report` 报告是最值钱的一屏**
- 分板块、有评级、有结论、有 90 天路线，看上去就是顾问交付物，不是 AI 摘要。
- 免费会员只看到前三个板块，后两块要升级——付费动机长在报告里，不靠推销。
- 最后一屏写明数据口径和合规边界，这是您的行业最需要的一句话。
- 纪要：「他只是这出一个人工报告的这种感觉。」

**`#/plans` 三层会员，让人自己往上走**
- 免费：预登记自动入会，一次军师体检，先把人留住。
- 学习会员 ¥99/月：智能体全开、每月闭门直播，这一层跑量。
- 品牌主理人：1 对 1 陪跑、门店诊断、大会席位，这一层才是我们真正要谈的客户。
- 纪要：「一种是免费进来，免费进来完以后我们再有个升级社群 99，再是有个升级社群跟高端的。」

**`#/store` 门店数据接入，只做一个示意**
- 收银台、美团、抖音本地生活、企业微信，接口都在，先做「已接入」的状态展示。
- 这一屏是给品牌老板看的：AI 化不是聊天，是能看见门店当天发生了什么。
- 军师每天给一条可执行的提醒，确认即发送——这就是持续付费的理由。
- 纪要：「扫码进入的排卡、收银台、美团订单都是接口的问题，相对也还是比较好实现的。」

## 完整演示动线（12 步，约 6 分钟）

```
小程序 A  ①展会首页 → ②预登记 → ③电子入场证 → ④同期论坛
              ↓（入场证底部按钮跳转）
小程序 B  ⑤消息（会话 + 你没进的群，指着 ¥9.9 讲付费墙）
              → ⑥点闭门群 → ¥9.9 解锁 → 回看同一行的前后变化
              → ⑦AI 军师 → ⑧诊断报告(免费/锁) → ⑨会员方案(升级) → ⑧'全量
              → ⑩运营主线（今天做什么 / 卡在第 3 步）
              → ⑪出片与分发（现场关掉 9.9 那个开关）
              → ⑫门店经营台（机器人日志 + 军师提醒）
```

两个「前后对比」是全场重点：第 ⑥ 步花 9.9 前后同一行的变化，
第 ⑪ 步自助出片开关关掉前后「拉新是收入还是纯成本」的差别。
