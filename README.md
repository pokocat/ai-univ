# AI Univ 协作总控仓库

这个仓库用于产品、设计与研发围绕多个项目协作。它采用 monorepo：跨项目资料和全部项目代码、设计资产都由这个仓库统一管理、统一提交。

## 目录约定

- `主理人/`：主理人项目。
- `wenquan/`：wenquan 项目。

## 使用方式

首次拉取仓库后，执行：

```bash
git clone https://github.com/pokocat/ai-univ.git
```

设计师或产品经理在对应项目目录内提交；所有变更均提交到这个仓库。跨项目的规范、共享资产和说明放在仓库根目录或后续约定的共享目录中。

## 新增项目

在仓库根目录创建一个新的项目目录并提交即可。不要在项目目录内初始化嵌套 Git 仓库，以免它脱离 monorepo 的统一版本管理。
